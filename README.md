# Portfolio Website — Tuguldur Turmunkh

Personal portfolio website showcasing web development projects, interactive media builds, technical skills, and professional experience.

## 🚀 Features

* **Interactive Project Showcase:** Highlights key projects such as *Immerse Mongolia*, *Baaz ERP*, *SITE Campus 360 Virtual Tour*, *AutoNation.mn*, and *Tiny Finance*.
* **Resume & Experience Section:** Overview of education from the National University of Mongolia and past work history.
* **Contact & Social Links:** Direct access to GitHub, LinkedIn, email, and downloadable resume.
* **Responsive & Dark UI:** Modern terminal-inspired aesthetic optimized for all screen sizes.

## 🛠️ Tech Stack

* **Framework:** Next.js / React
* **Styling:** Tailwind CSS, Framer Motion
* **Languages:** TypeScript / JavaScript
