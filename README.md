# Ambitious Dev Portfolio

Create a modern, professional personal portfolio website for a junior software developer who recently graduated from university and is looking for their first full-time developer role.

Goal

The website should make me look professional, capable, motivated, and hireable without pretending that I have years of professional experience. Emphasize my university projects, personal projects, technical skills, problem-solving ability, and willingness to learn.

Design Direction

Create a clean, modern developer portfolio with a slightly minimalist aesthetic.

Dark mode as the primary theme

Professional but not overly corporate

Subtle animations and smooth transitions

Excellent typography and spacing

Responsive on desktop, tablet, and mobile

Avoid excessive gradients, glowing effects, or generic “AI developer” aesthetics

Make it feel like a real developer’s portfolio rather than a template

Use subtle code/developer-inspired visual elements where appropriate

Strong visual hierarchy

Fast loading and accessible

Include a light/dark mode toggle if appropriate

Tech Stack

Build the website using:

Next.js

React

JavaScript or TypeScript

 Tailwind CSS unless absolutely necessary

Lucide React or another lightweight icon library

Framer motion for animation graphics

Responsive design

Component-based architecture
